# Phase 2 — AI Coder

[Course](https://www.udemy.com/course/ai-coder-from-vibe-coder-to-agentic-engineer/) · 16.3 hrs · weeks 9–16 · Oct 26 – Dec 18, 2026

Curriculum course 2. Agentic coding as a professional discipline, in three course weeks:

1. **Vibe coding** — IDE agents (Cursor, Copilot, Codex, Antigravity), context engineering and
   `AGENTS.md`, OpenRouter, then two complete products built with an agent doing the typing.
2. **Vibe engineering** — Claude Code in depth: commands, checkpoints, Ralph loops, MCP, skills and
   plugins, then a Jira ticket → pull request workflow that builds a SaaS product.
3. **Expert** — sub-agents, hooks, sandboxes, agent teams and orchestrators, ending in a trading
   workstation capstone.

95 lectures. The lecture-by-lecture checklist, grouped by my study week, is in
[`TASKS.md`](TASKS.md).
